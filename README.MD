Программа "Повторите слово" <br>
Программа запрашивает у пользователя слово и выводит его обратно на экран.<br>
через стандартные потоки ввода (std::cin) и вывода (std::cout).<br>

Console Out:<br>
```
  Введите слово:
  Привет!
  Вы ввели:
  Привет!
```
Проект создан в учебных целях.
