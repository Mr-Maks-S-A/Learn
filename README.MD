Программа "Сумматор" <br>
  Программа для суммирования целых чисел, вводимых пользователем до ввода нуля.

  Примечания: Реализована устойчивость к некорректному вводу (буквы, символы).

Console Out:<br>
```
Введите целое число или число '0', чтобы закончить:
11
Введите целое число или число '0', чтобы закончить:
11
Введите целое число или число '0', чтобы закончить:
0
Сумма: 22
```

```
Введите целое число или число '0', чтобы закончить:
a
Ошибка! Пожалуйста, вводите только целые числа.
[СОСТОЯНИЕ: ОШИБКА ВВОДА. Повторите попытку]
Введите целое число или число '0', чтобы закончить:
12
Введите целое число или число '0', чтобы закончить:
0
Сумма: 12
```
Проект создан в учебных целях.
