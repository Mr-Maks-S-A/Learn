## Устранение дублирования
Программа демонстрирует использование функций для устранения дублирования кода
на примере возведения числа в целую положительную степень.<br>


Console Out:<br>
```
5 в степени 2 = 25
3 в степени 3 = 27
4 в степени 4 = 256
```
