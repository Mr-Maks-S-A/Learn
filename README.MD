Двумерный массив<br>
Программа создает массив 3x6, выводит его и находит индексы min/max элементов.<br>


Console Out:<br>
```
Массив:
12	45	7	23	56	18	
90	3	34	11	67	21	
5	88	42	99	14	30	

Индекс минимального элемента: 1 1
Индекс максимального элемента: 2 3
```
Проект создан в учебных целях.
