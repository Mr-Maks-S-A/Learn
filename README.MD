Программа "Гороскоп" <br>
Программа запрашивает данные пользователя (пол, знак зодиака, возраст)  <br>
и выводит персональное предсказание на основе заданных критериев.

Console Out:<br>
```
Введите пол (м/ж): м
Введите знак зодиака: рак
Введите возраст: 39
Сегодня очень плодотворный день. Можно добиться того, что прежде казалось почти невозможным.
```

```
Введите пол (м/ж): ж
Введите знак зодиака: телец
Введите возраст: 15
Сегодняшний вечер подходит для общения с друзьями, проведения домашних праздников и импровизированных вечеринок.
Будет не только весело, но и интересно: найдётся дело, которое увлечёт всех.
```
Проект создан в учебных целях.
