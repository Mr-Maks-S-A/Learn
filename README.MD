Максимум и минимум<br>
Программа создает массив из 10 целых чисел, выводит их на экран,<br>
после чего находит наименьшее и наибольшее значения в этом массиве.<br>


Console Out:<br>
```
Массив: 42 12 7 99 3 56 1 88 24 15
Минимальный элемент: 1
Максимальный элемент: 99
```
Проект создан в учебных целях.
