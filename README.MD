Программа "Таблица истинности" <br>
Она выводит таблицу истинности для логических операторов ||, &&, с применением логических выражений.

Console Out:<br>
```
Оператор: ||
true	true	true
false	true	true
true	false	true
false	false	false

Оператор: &&
true	true	true
false	true	false
true	false	false
false	false	false
```
Проект создан в учебных целях.
